---

## 📌 ¿Qué hace este Skill?

Guía de mejores prácticas para concebir, desarrollar, depurar y desplegar servidores de herramientas basadas en el estándar Model Context Protocol (MCP).

---

## ⚙️ ¿Cómo lo hace?

Estructura el desarrollo de servidores MCP:
- Definición de herramientas con esquemas JSON Schema rigurosos.
- Exposición de recursos estáticos y dinámicos legibles por modelos.
- Soporte para transportes estándar (STDIO y Server-Sent Events / SSE).
- Configuración de clientes y registro seguro en `mcp_config.json`.
