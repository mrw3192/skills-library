# Generative Interactive UI Widgets (`generative-ui`)

> **Categoría**: Agent Architecture & Multi-Agent Orchestration  
> **Autor / Creador**: Google DeepMind  
> **Fuente de origen**: [Google Antigravity Builtin Core](https://github.com/google/antigravity)

---

## 📌 ¿Qué hace este Skill?

Patrones para generar interfaces gráficas interactivas y widgets en HTML/CSS/JS renderizados directamente en el chat o en artefactos visuales.

---

## ⚙️ ¿Cómo lo hace?

Provee recetas de diseño para visualización de datos:
- Dashboards interactivos, tablas dinámicas con filtros, calculadoras reactivas y diagramas visuales generados al instante.
- Asegura que el código sea autosuficiente, seguro y compatible con el visor de artefactos sin dependencias externas bloqueadas por CSP.
