# Swarm Narrative Progress Reporter (`swarm-narrator`)

> **Categoría**: Agent Architecture & Multi-Agent Orchestration  
> **Autor / Creador**: Google DeepMind  
> **Fuente de origen**: [Google Antigravity Builtin Core](https://github.com/google/antigravity)

---

## 📌 ¿Qué hace este Skill?

Genera relatos continuos, ejecutivos y comprensibles para el usuario sobre los avances concurrentes de los agentes dentro de un enjambre.

---

## ⚙️ ¿Cómo lo hace?

Sintetiza la actividad masiva del enjambre:
- Filtra eventos técnicos de bajo nivel y comunica hitos clave completados por cada miembro del equipo autónomo.

- `resumen de enjambre`
- `narrar progreso swarm`
