# Plugin Packaging & Lifecycle Management (`plugin`)

> **Categoría**: Agent Architecture & Multi-Agent Orchestration  
> **Autor / Creador**: Google DeepMind  
> **Fuente de origen**: [Google Antigravity Builtin Core](https://github.com/google/antigravity)

---

## 📌 ¿Qué hace este Skill?

Manual para crear, empaquetar, instalar, habilitar y distribuir plugins de Antigravity (colecciones autocontenidas de skills, reglas, servidores MCP y hooks).

---

## ⚙️ ¿Cómo lo hace?

Maneja el ciclo de vida completo de un plugin:
- Creación de la estructura estándar (`plugin.json`, directorios `skills/`, `rules/`, etc.).
- Validación de esquemas y publicación o distribución a usuarios y Marketplace.
