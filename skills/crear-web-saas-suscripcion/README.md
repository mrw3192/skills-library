## 📌 ¿Qué hace este Skill?

Construye aplicaciones SaaS completas basadas en Inteligencia Artificial (Gemini) con modelo de suscripción mensual/anual, gestión de créditos de consumo y cuentas de usuario.

---

## ⚙️ ¿Cómo lo hace?

Estructura el SaaS mediante una arquitectura modular probada:
1. **Catálogo de 11 Arquetipos de IA**: Redacción inteligente de PDFs, conversión de facturas a Excel estructurado, análisis legal de contratos, transcripción y estructuración de notas manuscritas, traducción contextual de documentos, generación de fotos de producto, restyling de interiores, restauración de fotos antiguas y estimación de macronutrientes.
2. **Backend Proxy Seguro**: Protege las API keys en un backend intermedio seguro sin exponerlas en el frontend.
3. **Sistema de Créditos & Cuentas**: Gestión de sesiones, billetera de créditos por usuario y decremento transaccional por uso.
4. **Pasarela Mock a Real**: Prototipado inicial con checkout simulado para validación de interfaz, seguido de migración guiada a pasarelas reales (Stripe, Mercado Pago o Paddle) cuando el producto está terminado.
