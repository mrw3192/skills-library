## 📌 ¿Qué hace este Skill?

Compendio completo de capacidades de Google Antigravity, incluyendo comandos de CLI (`agy`), atajos de teclado, comandos slash (`/plan`, `/schedule`, `/teamwork`), y navegación del IDE.

---

## ⚙️ ¿Cómo lo hace?

Funciona como un mapa de sitio interactivo:
- Resuelve dudas sobre cómo operar la interfaz del agente, configurar modelos y ejecutar tareas en segundo plano.
- Enruta al usuario hacia la herramienta o comando específico más eficiente según la tarea que desea resolver.
