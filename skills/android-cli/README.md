# Android Command-Line Tools & Automation (`android-cli`)

> **Categoría**: Mobile & Android Tools  
> **Autor / Creador**: Android Developer Tools Team  
> **Fuente de origen**: [Google Android Developer Tools Team](https://developer.android.com/tools)

---

## 📌 ¿Qué hace este Skill?

Automatiza tareas críticas de desarrollo móvil Android mediante la herramienta de línea de comandos `android` y herramientas asociadas (Gradle, ADB, SDK Manager y AVD Manager).

---

## ⚙️ ¿Cómo lo hace?

Permite a los agentes interactuar con proyectos Android:
- Creación rápida de proyectos mediante plantillas (`empty-activity`, `compose`, etc.).
- Gestión de dispositivos virtuales de Android (AVD): creación, inicio, apagado y snapshots.
- Compilación y ejecución de aplicaciones en emuladores o terminales físicos con un solo comando.
- Inspección de la interfaz gráfica y extracción de capturas de pantalla de la pantalla del dispositivo para validación visual.
- Búsqueda y consulta de documentación oficial de Android y recomendaciones de arquitectura.

## 🎯 Disparadores y Palabras Clave (Triggers)

Este skill es activado automáticamente por el agente ante las siguientes intenciones o menciones:

- `android`
- `crear app android`
- `compilar android`
- `adb`
- `avd`
- `emulador android`
- `run android app`
