## 📌 ¿Qué hace este Skill?

Guía oficial y patrones de arquitectura para diseñar, implementar, depurar y poner en producción agentes de IA autónomos y sistemas multiagente utilizando el SDK de Python de Google Antigravity.

---

## ⚙️ ¿Cómo lo hace?

Establece las mejores prácticas para el framework Antigravity:
- Verificación del entorno (`google-antigravity` package) y autenticación mediante `GEMINI_API_KEY`.
- Patrones de configuración con `LocalAgentConfig`, `AgentServer` y gestión de estado persistente.
- Orquestación avanzada mediante la Interactions API, Decisions API y Live API de Gemini.
- Implementación de herramientas personalizadas (tools), control de memoria y manejo seguro de excepciones en agentes autónomos.
