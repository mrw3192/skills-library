# Android Device Hub Sidecar & Mirroring (`android-device-hub`)

> **Categoría**: Mobile & Android Tools  
> **Autor / Creador**: Android Developer Tools Team  
> **Fuente de origen**: [Google Android Developer Tools Team](https://developer.android.com/tools)

---

## 📌 ¿Qué hace este Skill?

Proporciona integración con el sidecar interactivo Device Hub para visualizar, duplicar (screen mirroring) y controlar en tiempo real dispositivos Android virtuales y físicos conectados.

---

## ⚙️ ¿Cómo lo hace?

Opera como puente visual y de control entre el agente y el dispositivo:
- Lista, inicia y detiene emuladores y dispositivos conectados por ADB.
- Transmite video en vivo de la pantalla del dispositivo dentro de un panel en el IDE.
- Permite enviar eventos táctiles (toques, deslizamientos), pulsaciones de teclado y navegación por hardware.
- Provee comandos como `android layout` y `android screen` para obtener la jerarquía visual de elementos en pantalla para pruebas guiadas por IA.
