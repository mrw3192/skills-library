# Client Website Studio as a Service (`crear-web-como-servicio`)

> **Categoría**: Commercial & Monetization Web Apps  
> **Autor / Creador**: Skilio / Client Studio v2  
> **Fuente de origen**: [Skilio (5 Skills para Ganar Dinero)](https://recursos.skilio.com/5-skills-ganar-dinero/)

---

## 📌 ¿Qué hace este Skill?

Diseña y construye sitios web de nivel agencia listos para vender como servicio a negocios locales y empresas (instaladores solares, clínicas, estudios contables/legales, gimnasios, restaurantes). Incluye integración de asistentes conversacionales con IA, lectores inteligentes de documentos y calculadoras interactivas.

---

## ⚙️ ¿Cómo lo hace?

Guía el ciclo comercial y técnico completo en 5 fases:
1. **Conexión Hostinger**: Vinculación de infraestructura del cliente o propia.
2. **Diseño de Grado Agencia**: Frontend estático sin compiladores (HTML/CSS/JS nativo) con acabados visuales de alto valor percibido (estilo proyecto de $30.000).
3. **Curaduría Visual**: Búsqueda e integración automática de recursos multimedia libres de derechos (Openverse) o generación a medida vía IA.
4. **Funcionalidades de IA Seguras**: Chatbot de soporte con Gemini, analizador de documentos/facturas (OCR visual) y calculadoras de cotización instantánea utilizando un proxy seguro para proteger API keys.
5. **Publicación y Conexión de Dominio**: Despliegue en producción con configuración de DNS y dominio personalizado.
