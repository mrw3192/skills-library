# Background Automation & Scheduler Designer (`automation`)

> **Categoría**: Agent Architecture & Multi-Agent Orchestration  
> **Autor / Creador**: Google DeepMind  
> **Fuente de origen**: [Google Antigravity Builtin Core](https://github.com/google/antigravity)

---

## 📌 ¿Qué hace este Skill?

Guía interactiva para diseñar, configurar y programar automatizaciones que se ejecutan en segundo plano o de forma periódica.

---

## ⚙️ ¿Cómo lo hace?

Asiste en la formulación de tareas programadas:
- Traduce necesidades de usuario a expresiones cron estandarizadas o temporizadores únicos.
- Configura condiciones de reactivación (`TimerCondition`), límites de iteraciones (`MaxIterations`) y comportamiento demonio para tareas independientes.
