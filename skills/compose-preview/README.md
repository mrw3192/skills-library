# Jetpack Compose Preview Sidecar (`compose-preview`)

> **Categoría**: Mobile & Android Tools  
> **Autor / Creador**: Android Developer Tools Team  
> **Fuente de origen**: [Google Android Developer Tools Team](https://developer.android.com/jetpack/compose)

---

## 📌 ¿Qué hace este Skill?

Renderiza y visualiza funciones `@Preview` de Jetpack Compose en un panel lateral interactivo sin necesidad de compilar o desplegar la aplicación completa en un emulador.

---

## ⚙️ ¿Cómo lo hace?

Agiliza el desarrollo de interfaz en Android:
- Ejecuta `android preview render` para compilar aisladamente los componentes Composable anotados.
- Despliega las vistas resultantes en el sidecar de Compose Preview dentro del entorno de desarrollo.
- Facilita ciclos rápidos de iteración: el agente modifica el código Compose y solicita el re-renderizado para verificar instantáneamente márgenes, colores, estados y soporte para temas oscuros.
