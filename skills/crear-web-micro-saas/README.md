## 📌 ¿Qué hace este Skill?

Desarrolla sitios web de micro-herramientas utilitarias y calculadoras (Micro-SaaS) que se ejecutan 100% en el navegador del cliente sin costes de backend, diseñados para monetización mediante publicidad (AdSense/Mediavine) o membresías.

---

## ⚙️ ¿Cómo lo hace?

Aprovecha un catálogo de 25 arquetipos pre-validados:
- Generadores de códigos QR, convertidores de formatos de archivo, optimizadores de imagen (compresión WebP/PNG en cliente).
- Herramientas PDF (unir, dividir, extraer), pruebas de velocidad de red, lookup de IP, OCR en navegador y eliminación de fondos con Canvas/WebAssembly.
- Arquitectura 100% client-side: sin servidores, sin bases de datos remotas ni consumo de claves API de pago.
- Flujo desacoplado: conexión de hosting, construcción del arquetipo y publicación directa a Hostinger.
