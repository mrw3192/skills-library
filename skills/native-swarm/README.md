# Multi-Agent Native Swarm Orchestration (`native-swarm`)

> **Categoría**: Agent Architecture & Multi-Agent Orchestration  
> **Autor / Creador**: Google DeepMind  
> **Fuente de origen**: [Google Antigravity Builtin Core](https://github.com/google/antigravity)

---

## 📌 ¿Qué hace este Skill?

Orquestación de enjambres (swarms) multiagente donde múltiples agentes especializados colaboran en paralelo comunicándose a través de un tablero de mensajes compartido.

---

## ⚙️ ¿Cómo lo hace?

Coordina la ejecución distribuida de tareas complejas:
- Spawnea agentes trabajadores asignándoles roles, asignaciones de trabajo claras y workspaces aislados (`share` o `branch`).
- Permite la supervisión colaborativa, el cruce de revisiones de código y la agregación de resultados de múltiples modelos en tiempo récord.
