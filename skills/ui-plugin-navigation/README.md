# UI Plugin Panel Navigation & Shortcuts (`ui-plugin-navigation`)

> **Categoría**: Agent Architecture & Multi-Agent Orchestration  
> **Autor / Creador**: Google DeepMind  
> **Fuente de origen**: [Google Antigravity Builtin Core](https://github.com/google/antigravity)

---

## 📌 ¿Qué hace este Skill?

Identifica y presenta accesos directos en el chat para abrir o conmutar paneles laterales e interfaces de usuario asociadas a plugins activos en el IDE.

---

## ⚙️ ¿Cómo lo hace?

Optimiza la ergonomía del entorno de trabajo:
- Detecta cuando un panel visual relevante (como Device Hub o Compose Preview) puede ayudar en la tarea actual.
- Genera botones interactivos de un clic en el chat para que el usuario abra instantáneamente el panel sin buscar en los menús.
