# 🧠 Skills Library — Biblioteca Centralizada de Skills para Agentes de IA

Repositorio centralizado de **Skills** para asistentes y agentes autónomos de Inteligencia Artificial ([Google Antigravity](https://github.com/google/antigravity), Claude Code, Cursor, Codex, etc.).

Cada skill contiene su archivo de instrucciones estandarizado `SKILL.md`, sus recursos complementarios (scripts, templates, referencias) y un `README.md` exhaustivo que detalla **qué hace**, **cómo lo hace** y **su referencia a la fuente de origen**.

## 🚀 Cómo Usar e Instalar estos Skills

### 1. En Google Antigravity / Gemini CLI
Para instalar cualquiera de estos skills en tu entorno global de Antigravity, copia la carpeta del skill deseado en:
```sh
# En Windows
%USERPROFILE%\.gemini\config\skills\<nombre-del-skill>

# En Linux / macOS
~/.gemini/config/skills/<nombre-del-skill>
```
O dentro de un proyecto específico en `.agents/skills/<nombre-del-skill>`.

### 2. En Claude Code / Cursor
Copia el contenido de la carpeta o el archivo `SKILL.md` dentro del directorio `.claude/skills/` o dentro de las instrucciones de contexto del agente.
